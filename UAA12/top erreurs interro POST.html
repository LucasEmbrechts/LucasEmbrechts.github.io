Échange de données via POST

Top 10 des (bêtes) erreurs

❌ ERREUR #1 : Oublier method="POST"

Formulaire sans méthode ou method incorrect

<!-- INCORRECT -->
<form action="reservation.php">
<input type="text" name="nom">
</form>

<!-- INCORRECT -->
<form method=$_POST>
❌ Sans method="POST", les données vont en GET
⚠️ $_POST vide - données dans l'URL
✅ SOLUTION #1 : Toujours method="POST"

Méthode POST explicite dans le formulaire

<!-- CORRECT -->
<form action="reservation.php" method="POST">
<input type="text" name="nom">
<input type="submit">
</form>
✅ method="POST" ou method="post"
✅ Données envoyées via POST
❌ ERREUR #2 : Oublier l'attribut name

Input sans name ou name vide

<!-- INCORRECT -->
<input type="text" id="nom">
<input type="text">

// PHP
$nom = $_POST["nom"];
❌ Sans name, pas d'envoi au serveur
⚠️ $_POST["nom"] n'existe jamais
✅ SOLUTION #2 : Attribut name obligatoire

Chaque input doit avoir un name

<!-- CORRECT -->
<input type="text" name="nom" id="nom">
<input type="text" name="date">

// PHP
$nom = $_POST["nom"];
✅ name = clé dans $_POST
✅ Données transmises correctement
❌ ERREUR #3 : $_POST avant isset()

Accéder à $_POST sans vérification

// INCORRECT
$nom = $_POST["nom"];
$service = $_POST["service"];

echo "Merci $nom";
❌ Au chargement de la page, $_POST vide
⚠️ "Undefined array key" - erreur PHP
✅ SOLUTION #3 : TOUJOURS isset()

Vérifier avant d'utiliser $_POST

// CORRECT
if(isset($_POST["nom"]) &&
isset($_POST["service"])) {
$nom = $_POST["nom"];
$service = $_POST["service"];
echo "Merci $nom";
}
✅ isset() vérifie que les données existent
✅ Plus d'erreur au premier chargement
❌ ERREUR #4 : Point-virgule après isset()

; termine le if avant le code

// INCORRECT
if(isset($_POST["nom"]) &&
isset($_POST["service"]));
$nom = $_POST["nom"];
echo "Merci $nom";
❌ Le ; coupe le if - code s'exécute toujours
⚠️ Erreur car $_POST utilisé sans vérification
✅ SOLUTION #4 : Pas de ; après if

Le if contrôle le bloc suivant

// CORRECT
if(isset($_POST["nom"]) &&
isset($_POST["service"])){
$nom = $_POST["nom"];
echo "Merci $nom";
}
✅ Pas de ; - accolades directement
✅ Le code s'exécute seulement si isset() vrai
❌ ERREUR #5 : Syntaxe isset() incorrecte

= au lieu de [] pour isset()

// INCORRECT
$nom = isset($_POST = "nom");
$service = isset($_POST = "service");

echo "Merci $nom";
❌ isset($_POST = ...) est invalide
⚠️ Erreur de syntaxe - code ne fonctionne pas
✅ SOLUTION #5 : Crochets [] pour isset()

isset() vérifie, puis assignation

// CORRECT
if(isset($_POST["nom"]) &&
isset($_POST["service"])){
$nom = $_POST["nom"];
$service = $_POST["service"];
echo "Merci $nom";
}
✅ isset($_POST["clé"]) puis affectation
✅ Syntaxe correcte
❌ ERREUR #6 : Options sans value

<option> sans attribut value

<!-- INCORRECT -->
<select name="service">
<option>Médecine générale</option>
<option>Kinésithérapie</option>
</select>

// PHP - comparaison difficile
if($service == "Médecine générale"){
❌ Texte complet envoyé - sensible aux espaces/accents
⚠️ Comparaisons fragiles
✅ SOLUTION #6 : Toujours value sur <option>

Valeur courte et simple

<!-- CORRECT -->
<select name="service">
<option value="medecine">Médecine générale</option>
<option value="kine">Kinésithérapie</option>
</select>

// PHP - comparaison simple
if($service == "medecine"){
✅ value = code simple sans accent
✅ Comparaisons fiables
❌ ERREUR #7 : Pas de bouton submit

Button normal au lieu de submit

<!-- INCORRECT -->
<form method="post">
<input type="text" name="nom">
<input type="button" value="Envoyer">
</form>

❌ type="button" n'envoie pas le formulaire
⚠️ Clic ne soumet rien - $_POST vide
✅ SOLUTION #7 : type="submit"

Submit soumet le formulaire

<!-- CORRECT -->
<form method="post">
<input type="text" name="nom">
<input type="submit" value="Envoyer">
</form>

✅ type="submit" envoie le formulaire
✅ Données POST transmises au clic
❌ ERREUR #8 : Accolades au lieu de parenthèses

rand(0,5){ au lieu de rand(0,5)

// INCORRECT
$nombre = rand(0, 5){
echo "RES-".$nombre;
}
❌ { } ne sont pas pour les fonctions
⚠️ Erreur de syntaxe PHP
✅ SOLUTION #8 : Parenthèses pour fonctions

( ) pour appeler rand()

// CORRECT
$nombre = rand(0, 5);
echo "RES-".$nombre;
✅ Fonction = parenthèses ( )
✅ Nombre aléatoire généré
❌ ERREUR #9 : Syntaxe for en JavaScript

let dans une boucle PHP

// INCORRECT - mélange JS et PHP
for(let $i=0; $i<6; $i++){
echo rand(0,9);
}
❌ let est JavaScript, pas PHP
⚠️ Erreur de syntaxe
✅ SOLUTION #9 : Syntaxe PHP pure

for($i=...) en PHP

// CORRECT
for($i=0; $i<6; $i++){
echo rand(0,9);
}

// ou
for($cpt=1; $cpt<=6; $cpt++){
echo rand(0,9);
}
✅ Pas de let - juste $variable
✅ Boucle PHP correcte
❌ ERREUR #10 : Variables utilisées avant isset()

echo avec variables non vérifiées

// INCORRECT
if(isset($_POST["nom"])){
$nom = $_POST["nom"];
}
echo "Merci $nom";
echo "Service $service le $date";
❌ Variables utilisées en dehors du if
⚠️ Variables undefined au 1er chargement
✅ SOLUTION #10 : echo DANS le if

Afficher seulement si données présentes

// CORRECT
if(isset($_POST["nom"]) &&
isset($_POST["service"]) &&
isset($_POST["date"])){
$nom = $_POST["nom"];
$service = $_POST["service"];
$date = $_POST["date"];
echo "Merci $nom";
echo "Service $service le $date";
}
✅ Tout le code dans le if
✅ Pas d'erreur variable undefined
